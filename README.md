# DocClear AI

DocClear AI is a full-stack document quality assessment and enhancement system. It combines a React frontend, a FastAPI backend, classical computer-vision baselines, and a modular local OCR runtime.

## Current status

The repository currently includes the implemented upload, quality assessment, enhancement, OCR readability validation, and content-preservation workflow. The future deep-learning quality classifier remains a modular scaffold and has not been trained or added to the repository.

## Features

- Upload and analyze JPG, JPEG, PNG, and first-page PDF documents.
- Assess blur, brightness, contrast, noise, skew, cropping, and resolution.
- Create a separate enhanced derivative without modifying the original.
- Validate OCR readability before recommending an enhanced document.
- Run PaddleOCR locally through an isolated Python 3.12 CPU environment.
- Keep uploads, generated documents, datasets, checkpoints, and secrets out of Git.

## Project structure

```text
frontend/   React + Vite + Tailwind CSS application
backend/    FastAPI API, quality assessment, enhancement, and OCR integration
ml/         Modular dataset, training, evaluation, and inference workspace
docs/       Architecture, API, model, and project notes
scripts/    Project utility scripts
```

## Requirements

- Python 3.14 for the main FastAPI backend
- Python 3.12 for the isolated PaddleOCR runtime on Windows CPU
- Node.js and npm for the frontend

## Setup and run

### Backend

From the repository root:

```powershell
cd backend
python -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
python -m pip install -r requirements.txt
uvicorn app.main:app --reload
```

The API runs at `http://127.0.0.1:8000`.

### Frontend

In another terminal:

```powershell
cd frontend
npm install
npm run dev
```

### Local OCR runtime

The main backend stays on Python 3.14. PaddleOCR runs in a separate Python 3.12 environment and is called through a fixed local subprocess boundary.

```powershell
py -3.12 -m venv backend\\.venv-ocr
backend\\.venv-ocr\\Scripts\\python.exe -m pip install --upgrade pip
backend\\.venv-ocr\\Scripts\\python.exe -m pip install -r backend\\ocr-requirements.txt
backend\\.venv-ocr\\Scripts\\python.exe -c "import paddle, paddleocr; print(paddle.__version__); print(paddleocr.__version__); print(paddle.device.get_device())"
```

The runner accepts only controlled temporary image paths generated by the backend, uses the fixed OCR Python executable, disables arbitrary shell execution, applies a timeout, returns structured JSON, and removes temporary OCR inputs after use.

## API endpoints

- `GET /health`
- `POST /api/documents/analyze`
- `POST /api/documents/{document_id}/enhance`
- `GET /api/documents/{document_id}/enhanced`

## Verification

```powershell
cd backend
python -m pytest -q

cd ..\\frontend
npm run build
```

The quality and enhancement pipelines are baseline engineering implementations. They do not establish document authenticity or factual correctness, and multi-page PDF processing is not implemented yet.

## Repository hygiene

Do not commit API keys, passwords, uploaded documents, generated document images, datasets, virtual environments, or model checkpoints. Use `.env.example` files for configuration documentation only.
